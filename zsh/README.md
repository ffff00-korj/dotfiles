# Zsh Configuration

Конфигурация Zsh с Oh My Zsh, включающая плагины для продуктивной работы.

## 📦 Плагины и настройки

- **Oh My Zsh** — фреймворк для управления конфигурацией Zsh
- **zsh-autosuggestions** — автодополнение на основе истории команд
- Кастомный `zshrc` с персональными алиасами и функциями

## 🚀 Установка

```bash
make zsh
```

## 📝 Конфигурационные файлы

- `zshrc` — основной конфигурационный файл Zsh
